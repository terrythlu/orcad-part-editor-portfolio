01 · 設計圖

RTL 是什麼？它跟 Verilog 差在哪裡？

RTL = Register Transfer Level

翻成白話：描述資料在「暫存器（Register）」之間如何移動、如何經過邏輯運算，以及什麼時候更新。

可以把每一個暫存器想成有快門的照相機，只有 clock 指定的瞬間才把目前的值拍下來。

Verilog = 寫法 / 語言

Verilog 是硬體描述語言（HDL）；RTL 是一種設計抽象層級。

你可以用 Verilog、SystemVerilog 或 VHDL 來寫 RTL。不是所有 Verilog 程式都能合成成電路，例如模擬用的延遲語法。

一張圖看懂：一個 clock，把資料從 FF1 送到 FF2

在 clock 邊緣，FF2 把「經過組合邏輯」的資料抓進來。這段資料路徑，就是後面要做 setup timing 檢查的主角。

大學寫過的 Verilog：這段程式會變成什麼？

// 兩個暫存器：a、b；一個 AND 邏輯
always @(posedge clk) begin
    a <= input_data;    // clock 來時，a 抓輸入
    b <= a & enable;   // b 抓的是「舊的 a」與 enable 的結果
end
很重要：<= 是時序邏輯常用的 nonblocking assignment。上面兩行不是 C 語言那樣「先更新 a，再更新 b」。在同一個 clock 邊緣，a、b 會依照該邊緣前的值進行更新；所以 b 用的是上一拍的 a。
面試講法：「Verilog 是 HDL，RTL 是用它描述暫存器和暫存器之間的資料運算。跟 C 最大的差異，是硬體有並行邏輯和 clock 取樣的觀念。」
02 · 時間規則

Setup Time 違反，究竟是什麼？

把 FF 想成拍照的相機。拍照前，物體要先站穩一小段時間；不能剛好在按快門前 0.01 秒才衝進鏡頭。

Setup Time

資料 D 必須在有效的 clock 邊緣之前，維持穩定至少一段時間。

太晚到 → Setup violation。

Hold Time

資料 D 必須在有效的 clock 邊緣之後，再維持穩定一段時間。

太早改變 → Hold violation。

先看圖：綠色是可以抓到的安全資料；紅色代表太晚改變

這是示意波形，不代表任一 FPGA 的實際 setup/hold 規格。每個 FF 的數值要看器件 timing model。

自己動手試：資料越晚到，越容易違反 Setup

這個滑桿只示範基本時間關係，實際 STA 還需考慮 clock-to-Q、組合邏輯延遲、routing、clock skew、uncertainty 等因素。

WNS = -0.25 ns 跟 setup 的關係

假設某條需要被檢查的路徑，要求資料最晚 9.75 ns 抵達，但實際是 10.00 ns 才到：

Slack = 9.75 − 10.00 = −0.25 ns

負值表示在這個 setup 檢查中晚了 0.25 ns。WNS 指的是整個 timing 報告中最糟糕的 setup slack（通常是多條路徑裡最負的一條）。

別弄混：「WNS = -0.25 ns」不是說 FF 的 setup time 是 -0.25 ns，而是實際到達時間比允許的最晚時間晚了 0.25 ns。違反可能造成錯誤取樣、亞穩態或不可靠運作；不代表每一拍都會失敗。
面試講法：「Setup violation 是 D 在有效 clock 邊緣前，沒有滿足 FF 要求的穩定時間。我會先找出 critical path，檢查邏輯延遲、布線延遲、clock skew 和約束，再考慮 pipeline 或改善邏輯。」
03 · CPLD 的典型積木

Macrocell 到底是什麼？

把傳統 CPLD 的 macrocell 想成「一間小型邏輯工作室」：裡面有多個 AND 條件，能把它們用 OR 合起來，還可能內建 FF、輸出選擇及 enable 控制。

先從你熟悉的電路開始：Y = (A AND B) OR (B AND C)

上面的兩個 AND 條件叫 product terms（積項）。多個積項用 OR 合併，叫 Sum of Products（SOP，積項和）。這是傳統 macrocell-based CPLD很常見的邏輯做法。

Macrocell 可以做什麼？

1. 算條件：例如 A & B。
2. 合併條件：例如 (A&B)|(B&C)。
3. 視需要由內部 FF 記住輸出。
4. 連到 I/O 或其他 macrocell。

一整顆 CPLD 是怎麼組成？

把許多宏單元接在一起，中間用可程式化連線矩陣分配訊號。它很適合板子的控制工作，例如 reset、power sequencing、chip enable、簡單狀態機。

面試講法：「傳統 CPLD 常用 macrocell-based 架構；macrocell 透過 product terms 組合邏輯，也可以接內建 FF，再利用可程式化互連矩陣串接多個 logic block。」
04 · FPGA 的典型積木

LUT 和 FF 又是什麼？

LUT = Look-Up Table = 查表做邏輯

想像你先把所有可能的輸入組合，以及對應的答案，全部寫在表格裡。輸入一進來，LUT 就直接查出答案。所以 LUT 是可以實現邏輯函數的一種電路資源。

一個 2-input LUT 做 AND

輸入 A、B，每個只有 0 或 1，總共有 4 種組合，所以只需要一張 4 列的表。

ABY = A AND B
000
010
100
111

同一顆 LUT，也能變 OR、XOR…

只要改變 LUT 內存的答案，LUT 就能做不同的邏輯。真實 FPGA 常見較大的 LUT（例如 4-input、6-input），能處理更多輸入。

2-input LUT 只有 4 種輸入組合；6-input LUT 有 64 種。這裡用 LUT2 只是比較好懂。

FF = Flip-Flop = 在 clock 邊緣記住 1 bit

如果說 LUT 像「計算機」，FF 就像「記憶格」。LUT 的輸出會隨 A/B 改變；FF 的 Q 則要等有效 clock 邊緣，才更新成當下 D 的值。

實際操作：先改 A/B，再按 Clock

下方把 LUT = A AND B 接到 FF 的 D 腳。請你先切換輸入，觀察 LUT 輸出；再按「送出 Clock」觀察 Q。

FPGA 的「豐富資源」指什麼？

FPGA 晶片裡通常不只有 LUT/FF。你可以想像它是很多小運算單元、記憶體、乘法器、時脈電路、I/O 和連線網路組成的「大型可編輯電路城市」。

BRAM：晶片裡面的 RAM，用來暫存一批資料。
DSP：加乘運算的專用單元，例如訊號處理。
Clock 資源：PLL／MMCM、clock routing，管理時脈。
I/O：連接外部腳位與周邊電路。
高速收發器：部分 FPGA 有高速 SerDes。
Routing：把 LUT、FF、BRAM 等接成你想要的電路。
面試講法：「LUT 是可程式化查表邏輯，FF 是受 clock 控制的暫存器。FPGA 由大量 LUT/FF 和可程式化 routing 組成，還會有 BRAM、DSP、Clock、I/O 等專用資源，適合較複雜的資料處理與介面控制。」
05 · 不要死背

所以 CPLD 和 FPGA 到底差在哪裡？

你要比較的東西傳統 macrocell 型 CPLD典型 LUT 型 FPGA
主要邏輯積木Macrocell：AND/OR product terms，常含 FFLUT + FF（搭配 routing）
想成什麼？少量、較固定的大型邏輯工作室大量、可自由排列的小型邏輯積木
典型任務Power/reset sequence、glue logic、簡單 FSM高速資料路徑、協定處理、DSP、較複雜 FSM
資源特性規模較小、常用非揮發配置邏輯資源較多、常內建 BRAM/DSP/Clock 等
有沒有 FF？有，許多 macrocell 內就有 FF有，LUT 配合 FF 使用
面試一定要加這句：「這是典型差異，不是絕對規則。」例如 Intel／Altera MAX II、MAX V 是 CPLD 產品家族，但內部基本邏輯元件也使用 LUT + register。因此不能說「凡是 CPLD 就一定沒有 LUT」。同樣地，FPGA 也不一定全部用 SRAM 配置。

把你原本的工作背景接進面試答案

「我過去比較熟系統板上的 clock、reset、power sequencing、介面與驗證。若把這些控制功能放到 programmable logic 裡，簡單邏輯可以使用 CPLD，較複雜的功能則會評估 FPGA。我知道 RTL 會描述暫存器和組合邏輯，實際實作時要留意 setup / hold timing；CPLD 的傳統 macrocell 與 FPGA 的 LUT/FF 也是不同的資源組織方式。」

這是表達你理解系統整合與基本原理的說法；若沒有親自做過 FPGA RTL 專案，不要把它說成已具備完整設計和 timing closure 經驗。

用 4 題確認你真的懂

Q1. RTL 是某一種晶片，還是描述電路的方法？

是描述電路的方法／抽象層級。例如用 Verilog 寫 RTL，描述資料如何在 FF 之間運算與傳遞。

Q2. 什麼情況會 setup violation？

資料在有效 clock 邊緣前，沒有提前滿足 FF 的 setup time 要求，例如資料太晚到。這是 timing 檢查，不等於 C 程式語法錯誤。

Q3. LUT 和 FF 分別做什麼？

LUT 做組合邏輯運算；FF 在clock 邊緣把 D 的值存成 Q。你可以回到上面的互動區實測。

Q4. CPLD 一定只有 Macrocell、沒有 LUT 嗎？

不一定。傳統 CPLD 常見 macrocell／product-term 架構，但 MAX II／MAX V 等 CPLD 使用 LUT-based 邏輯元件。
